WeatherWear — Smart Outfit Suggestions Based on Real-Time Weather

WeatherWear is a responsive, React-based web application that helps users decide what to wear by displaying dynamic outfit suggestions based on current weather conditions. Powered by the OpenWeather API, the app automatically updates its interface and weather card visuals to reflect real-time weather data.

🌦️ Features
👕 What to Wear Recommendations
Provides automated clothing suggestions based on temperature and weather conditions.
Helps users plan their day with confidence—no more guessing what to wear.

🌤️ Dynamic Weather Card
Weather card updates visually depending on current conditions (sunny, cloudy, rain, cold, etc.).
Displays temperature, location, weather description, and icons pulled from API data.

⚛️ Built With React & JSX
Fully built using React and modern JSX component structure.
Organized, reusable components for clean and scalable front-end architecture.

🌐 OpenWeather API Integration
Real-time weather data fetched directly from OpenWeather.
API responses dynamically update UI and outfit suggestions.

🎨 Custom CSS Styling
Clean, modern UI built using custom CSS.
Thoughtfully styled components for an intuitive user experience.

📱 Responsive Design
Mobile-first layout that adapts seamlessly to various screen sizes.
Fully responsive for phones, tablets, and desktops.
